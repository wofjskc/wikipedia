Docker

Docker — программное обеспечение для автоматизации развёртывания и управления приложениями в средах с поддержкой контейнеризации. Позволяет «упаковать» приложение со всем его окружением и зависимостями в контейнер.

Установка [править]

Установка в Альт 10 и старше

Для установки Docker в Альт 10 и более новых версиях выполните:

# apt-get update
# apt-get install docker-engine

Установка в p9 и ранее

В более старых версиях пакет назывался иначе:

# apt-get update
# apt-get install docker-ce

Настройка [править]

Автозапуск

Для включения автозапуска Docker при старте системы:

# systemctl enable docker
# systemctl start docker

Проверить статус службы:

# systemctl status docker

Запуск от пользователя

По умолчанию Docker требует прав суперпользователя. Чтобы запускать команды docker от обычного пользователя, добавьте его в группу docker:

# usermod -aG docker username
Внимание: После добавления пользователя в группу необходимо перелогиниться в системе или выполнить команду newgrp docker.

Также можно использовать команду:

# gpasswd -a username docker

Настройка хранилища

По умолчанию Docker хранит данные в /var/lib/docker. Для изменения расположения создайте или отредактируйте файл /etc/docker/daemon.json:

{
  "data-root": "/path/to/docker/data"
}

После изменения перезапустите Docker:

# systemctl restart docker

Использование [править]

Работа с образами

Скачать образ из Docker Hub:

$ docker pull ubuntu:22.04

Просмотр списка скачанных образов:

$ docker images

Удаление образа:

$ docker rmi image_name

Поиск образов:

$ docker search nginx

Работа с контейнерами

Запуск контейнера в интерактивном режиме:

$ docker run -it ubuntu:22.04 /bin/bash

Запуск контейнера в фоновом режиме:

$ docker run -d --name mycontainer nginx

Просмотр запущенных контейнеров:

$ docker ps

Просмотр всех контейнеров (включая остановленные):

$ docker ps -a

Остановка контейнера:

$ docker stop container_name

Запуск остановленного контейнера:

$ docker start container_name

Удаление контейнера:

$ docker rm container_name

Просмотр логов контейнера:

$ docker logs container_name

Выполнение команды в запущенном контейнере:

$ docker exec -it container_name /bin/bash

Docker Compose [править]

Docker Compose — инструмент для определения и запуска многоконтейнерных приложений.

Установка:

# apt-get install docker-compose

Пример файла docker-compose.yml:

version: '3.8'
services:
  web:
    image: nginx:latest
    ports:
      - "80:80"
    volumes:
      - ./html:/usr/share/nginx/html
  
  db:
    image: postgres:15
    environment:
      POSTGRES_PASSWORD: secret
    volumes:
      - pgdata:/var/lib/postgresql/data

volumes:
  pgdata:

Основные команды Docker Compose:

# Запуск всех сервисов
$ docker-compose up -d

# Остановка всех сервисов
$ docker-compose down

# Просмотр логов
$ docker-compose logs -f

# Пересборка образов
$ docker-compose build

# Просмотр статуса
$ docker-compose ps

Возможные проблемы [править]

Cannot connect to the Docker daemon

Если появляется ошибка:

Cannot connect to the Docker daemon at unix:///var/run/docker.sock. Is the docker daemon running?

Убедитесь, что служба Docker запущена:

# systemctl start docker

Permission denied

Если появляется ошибка прав доступа, добавьте пользователя в группу docker (см. раздел Запуск от пользователя).

Проблемы с сетью

Если контейнеры не имеют доступа к сети, проверьте настройки iptables и firewalld:

# systemctl status firewalld
# iptables -L -n

Может потребоваться разрешить форвардинг:

# echo 1 > /proc/sys/net/ipv4/ip_forward

Для постоянного применения добавьте в /etc/sysctl.conf:

net.ipv4.ip_forward = 1

Нехватка места

Для очистки неиспользуемых данных Docker:

# Удаление остановленных контейнеров
$ docker container prune

# Удаление неиспользуемых образов
$ docker image prune

# Полная очистка (контейнеры, образы, сети, кеш)
$ docker system prune -a
